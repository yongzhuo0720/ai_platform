## 二、AI 网关调用链（核心）

```
AiGatewayController /api/aiGateway/{module}/**  OR  OpenAiCompatController /v1/**
   │  (站内登录态 / 平台 sk- Token)
   ▼
AiGatewayAsyncDispatcher (WebAsyncTask 异步，不占 Web 线程)
   ▼
AiGatewayService.doProxyEntry
   ├─ 配置/uid/module 校验 + DifyEndpointPolicy 路径白名单
   ├─ AiGatewayConfigResolver 取地址密钥 (DB > 环境变量)
   ├─ AiGatewayGuard.check 限流+配额 → reserve 预扣 token
   ▼
AiGatewayService.doProxy
   ├─ AiIdempotencyGuard.acquire     幂等占位 (Redis SETNX 10min)
   ├─ GatewayConcurrencyGuard        并发闸门 (Redis ZSET+Lua)
   ├─ GatewayCircuitBreaker          熔断 (进程内, CLOSED→OPEN→HALF_OPEN)
   ├─ 构造上游请求 + X-Request-Id 透传 + 取消即 abort
   ├─ SSE 边读边写(心跳 : ping) / JSON 中继
   ├─ AiGatewayUsageParser 嗅探 tokens/model/会话ID/终止信号
   └─ finally: settle 预扣多退少补 + record 审计落 aicalllogbean
                                      └─ GatewayMetrics 输出 Prometheus 指标
   ▼
上游 Dify / OpenAI 兼容模型 (真实模型已验证: DeepSeek + 硅基)
```

**治理组件状态域**：

| 组件 | 状态存储 | 作用域 |
|---|---|---|
| 限流 / 配额 / 预扣结算 | Redis | 全局 |
| 幂等 / 并发闸门 | Redis (Lua) | 全局 |
| 定时任务互斥 | Redis (Lua) | 全局 |
| 熔断 | 进程内 ConcurrentHashMap | 每实例独立（有意取舍，见遗留清单） |
| 登录态 | Redis (Sa-Token) | 全局 |

## 三、本地 RAG 链路

```
上传 uploadFile
  → KbDocPipelineHolder (解析/去重/queued/正文入库)
  → kbDocExecutor 线程池 (core1/max2/queue20)
  → KbDocRunner: QUEUED→CHUNKING→EmbeddingClient分批向量化(批32,重试2)
                 → 一次性写 kbchunkbean → READY + 站内通知
  → 僵死回收 @Scheduled 每5min (Redis锁+CAS)
  → 孤儿分块对账 @Scheduled 每天03:00 (只读告警,不删数据) ← 本次新增

检索 search
  → 向量路(内存余弦) + 关键词路(PG全文检索 GIN索引)
  → RRF 融合(K=60) → 可选 Rerank(异常降级)
  → applyKnowledgeContext 注入 system 消息(≤8片/6000字) + kb-sources SSE事件

RAG 评估: RagEvaluator 只做检索侧指标(Recall/Precision/MRR/NDCG)
```

## 四、数据模型（关键表）

```
用户权限:  userbase │ role │ unit │ lable
AI治理:    aicalllogbean(costCents毫分) │ aiuserquotabean(token配额+成本预算)
           aiapitokenbean(只存tokenHash) │ aiweeklyreportbean │ notificationbean
模型配置:  modelsconfigbean │ difyconfigbean
会话:      chatconversationbean │ chatsharebean
RAG:       kbdocbean │ kbdoccontentbean │ kbchunkbean │ knowledgebase*
评估:      ragevaldatasetbean │ ragevalcasebean │ ragevalrunbean │ ragevalcaseresultbean
Agent:     agentbean │ agenttoolbean │ agentrunbean │ agentstepbean
```

表来源：框架 `@HnMapper(createTable=true)` 自动建表（jar 内） + `TableSchemaInitializer` 幂等补列建表（≥15 张显式） + `scripts/sql/` 脚本。

## 五、部署拓扑

```
                    ┌──────────────┐
                    │  Prometheus  │ (内网直连 app:8507 抓 /ai/actuator/prometheus)
                    └──────┬───────┘
                           │
┌──────────────────────────▼──────────────────────────────────────┐
│  docker-compose (4 服务)                                         │
│  nginx:8083(公网入口) → upstream app:8507 (可 --scale app=3)     │
│  app(expose 8507,不映射宿主) │ postgres:12.5 │ redis:6.2         │
└─────────────────────────────────────────────────────────────────┘
```

- 登录态在共享 Redis → 多副本无需 sticky
- SSO callback-url 必须指向 nginx 统一入口（8083），不能指向单实例 8507
