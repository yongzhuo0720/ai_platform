# 1 docker离线安装

上传【部署包>docker离线安装】文件夹下内容全部上传到服务器的/home/install下；

## 1.1 初始化目录

```shell
mkdir /home/docker

chmod -R 777 /home/install

chmod -R 777 /home/docker

ln -s /home/docker /var/lib/docker
```

## 1.2 安装docker

```shell
rpm -ivh /home/install/docker-ce-selinux-17.03.2.ce-1.el7.centos.noarch.rpm 

rpm -ivh /home/install/docker-ce-17.03.2.ce-1.el7.centos.x86_64.rpm
```

## 1.3 启动docker，并设置开机自启

```shell
systemctl enable docker

systemctl restart docker
```

## 1.4 检查docker运行

```shell
docker info
```

![img]( 01/clip_image002.jpg)

这两个命令可能会报错（依赖检测失败policycoreutils），加上以下指令：

```shell
rpm -ivh /home/install/docker-ce-selinux-17.03.2.ce-1.el7.centos.noarch.rpm --nodeps --force

rpm -ivh /home/install/docker-ce-17.03.2.ce-1.el7.centos.x86_64.rpm --nodeps --force
```

# 2 部署数据库

上传【部署包>pgsql】和【部署包>redis】文件夹下内容全部上传到服务器的/home/install下；

## 2.1 导入镜像 

```shell
docker load < /home/install/docker_redis.tar

docker load </home/install/docker_postgres.tar
```

![img]( 01/clip_image004.jpg)

## 2.2 解压配置

创建文件夹

```shell
mkdir -p /home/server

chmod -R 777 /home/server
```

下面的命令可以不执行，可以现在windows下解压，再上传

```shell
unzip /home/install/data_postgres.zip -d /home/server

unzip /home/install/data_redis.zip -d /home/server
```

最终形成/home/server/redis和/home/server/postgres文件夹

## 2.3 首次运行

```shell
docker run  --restart=always --name myredis -p 6379:6379 -v /home/server/redis/data:/data -v /home/server/redis/conf/redis.conf:/etc/redis/redis.conf -d redis redis-server /etc/redis/redis.conf

 
docker run --restart=always --name mypostgres -e POSTGRES_PASSWORD=zxcvbnm -e TZ=PRC -p 5432:5432 -v /home/server/postgres/data:/var/lib/postgresql/data -d postgres:12.5
```

## 2.4 查看运行情况,通过ps 记住容器ID 

```shell
docker ps
```

## 2.5 端口放行

```shell
firewall-cmd --zone=public --add-port=6379/tcp --permanent 

firewall-cmd --zone=public --add-port=3306/tcp --permanent 

firewall-cmd --reload
```
