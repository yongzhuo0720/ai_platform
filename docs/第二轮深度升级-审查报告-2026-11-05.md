### 1.5 数据库修改方案

项目**没有 Flyway/Liquibase**，DDL 三层：Bean 注解自动建表 → `TableSchemaInitializer.ensureXxx()` 幂等 DDL（新表/加列/索引）→ `scripts/sql/*.sql` 运维手工脚本，两份必须同步。

⚠️ **关键**：`ragevalrunbean` / `ragevalcaseresultbean` 已由 `ensureRagEval()` 建过表，只写 `CREATE TABLE IF NOT EXISTS` **不会补列**，必须显式 `ALTER TABLE ... ADD COLUMN IF NOT EXISTS`：

- `ragevalcaseresultbean`：`"retrievedHits" text`（JSON：Top-K 全序列 + 各路分数）、`"firstHitScore" float8`、`"hitChannel" varchar(16)`。

- PG 驼峰列名必须双引号；长文本 `@SqlColumn(method="text")`，存量表还要 `ALTER COLUMN TYPE text`。
- 回滚：停止读新列即可；物理回滚需备份后手工 `DROP COLUMN`，脚本不自动删。

### 3.2 建议新增（做「最小可执行闭环」，不做大而全）

一个 Agent = prompt + 模型 iid + 一组内置工具；一次运行 = 有上限的多步 `tool_calls` 循环。**不引 LangChain**，用现有 `HttpURLConnection` + `AiGatewayService` SSE + Jackson。

### 5.3 建议新增（全部用现有 Spring + Redis/PG，不引 Resilience4j/Sentinel/ShedLock）

1. **前端补 `Idempotency-Key`**（写请求 + 流式重试）+ `X-Request-Id` 透传；后端把 `409` 映射为可读提示。
2. **取消即时传播**：SSE 读循环改带超时的可读检测 / 独立看门狗，abort 后主动 `disconnect()`；补心跳。
3. **熔断与恢复**：Redis 存 `CLOSED/OPEN/HALF_OPEN` + 连续失败计数 + 半开探测许可；与 §4 共用一套。
4. **并发闸门**：`Semaphore` 或独立有界线程池按模块隔离，超限 429 不排队堆积。
5. **流式总时长护栏**：`deadline = now + maxStreamMs`（新配置项），每块检查；同时修「无 usage 正常结束」计费口径。

7. **多实例**：本地缓存改「短 TTL + Redis 版本号」或 pub/sub；`@Scheduled` 用 `AiIdempotencyGuard.java:82` 现成的 `setIfAbsent` 做分布式锁；周报补唯一索引 + 条件更新（替代 delete+insert）；文档流水线用 PG advisory lock。
8. **错误处理**：网关异常统一回固定中文文案 + `requestId`；前端按 `code` 分支。
