# IT 设备与账号安全管理规范

## 一、设备配发标准

| 岗位类型 | 笔记本配置 | 显示器 |
|---|---|---|
| 研发 | 32G 内存 / 1T SSD / i7 或 M3 Pro | 27 寸 2K ×1 |
| 设计 | 32G 内存 / 1T SSD / 独显 | 27 寸 4K ×1 |
| 职能 | 16G 内存 / 512G SSD | 24 寸 1080P ×1 |

设备使用满 3 年可申请更换。因个人原因损坏的，按折旧后残值赔偿；正常损耗不追责。

## 二、账号与密码

1. 所有系统账号统一使用公司邮箱前缀作为用户名。
2. 密码长度不少于 12 位，须包含大小写字母、数字与符号中的至少三类。
3. 密码每 90 天强制更换一次，且不得与最近 5 次使用过的密码重复。
4. 连续输错 5 次锁定账号 30 分钟；连续输错 10 次锁定 24 小时并通知 IT。
5. 严禁在便签、聊天工具、代码注释中明文保存密码。

## 三、多因素认证

以下系统强制开启 MFA（多因素认证）：

- VPN
- 生产环境跳板机
- 代码仓库管理员账号
- 财务系统
- 云平台控制台

MFA 采用 TOTP（30 秒刷新），不支持短信验证码。更换手机须提前在旧设备上解绑，否则需本人持工牌到 IT 柜台办理。

## 四、VPN 使用

1. VPN 仅限办公用途，连接后不得用于访问与工作无关的站点。
2. 默认分配 8 小时会话，超时自动断开，需重新认证。
3. 境外访问须事前申请，说明目的地与事由，由信息安全负责人审批。
4. VPN 账号不得共享，一人一号，日志留存 180 天。

## 五、数据分级与传输

| 级别 | 定义 | 传输要求 |
|---|---|---|
| L1 公开 | 可对外披露 | 无限制 |
| L2 内部 | 仅限员工 | 仅内网或加密邮件 |
| L3 机密 | 限于项目组 | 加密 + 审批 + 水印 |
| L4 绝密 | 限于特定人员 | 禁止外发，仅限离线介质 |

L3 及以上数据禁止上传到任何公网 AI 工具（含 ChatGPT、Claude、Kimi 等）。违反者按《员工奖惩条例》处理，情节严重的追究法律责任。

## 六、终端安全

1. 所有笔记本须安装公司统一的 EDR 客户端，禁止卸载。
2. 操作系统补丁须在发布后 7 日内安装。
3. 禁止关闭防火墙，禁止安装未经审批的远程控制软件。
4. 离开工位须锁屏（Win+L / Ctrl+Cmd+Q）。
5. USB 存储设备默认禁用，确需使用的须申请白名单。

## 七、安全事件上报

发现账号异常、设备丢失、数据泄露等情况，须在 1 小时内通过安全热线 8888 或 security@example.com 上报，不得自行处置或隐瞒。设备丢失须同时报警并取得报案回执。
