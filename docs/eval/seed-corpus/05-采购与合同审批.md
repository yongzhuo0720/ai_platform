# 采购、合同与付款审批流程

## 一、采购分类

| 类型 | 金额区间 | 审批路径 |
|---|---|---|
| 小额采购 | 5000 元以下 | 部门负责人 |
| 一般采购 | 5000-50000 元 | 部门负责人 + 采购部 |
| 大额采购 | 50000-300000 元 | 部门负责人 + 采购部 + 财务总监 |
| 重大采购 | 300000 元以上 | 上述 + 总经理 + 董事会授权 |

同一供应商、同一品类在 30 天内拆分下单规避审批的，视为违规，采购申请一律驳回。

## 二、供应商准入

1. 新供应商须提交营业执照、开户许可证、一般纳税人资格证明、近一年审计报告（金额 10 万元以上项目）。
2. 采购部负责资质初审，法务负责合同条款审核，财务负责信用评估。
3. 供应商须签署《廉洁承诺书》与《保密协议》。
4. 单一供应商年度采购额超过同品类 70% 的，须说明理由并引入备选供应商。

## 三、比价与招标

- 5000-50000 元：至少 3 家比价，留存比价单。
- 50000-300000 元：至少 3 家密封报价，采购部组织评审会。
- 300000 元以上：公开招标或邀请招标，评标委员会不少于 5 人，其中技术专家不少于 2 人。

## 四、合同审批

1. 合同须使用公司法务部提供的标准模板；使用对方模板的，法务须逐条审核并出具意见。
2. 审批流：业务发起 → 部门负责人 → 法务 → 财务 → 分管副总 → 用印。
3. 合同金额 100 万元以上或涉及知识产权归属、独家授权的，须总经理签批。
4. 严禁先履行后补合同。确因业务紧急需先行履行的，须取得总经理书面同意，并在 10 个工作日内补签。

## 五、付款

1. 付款方式优先选择银行转账，禁止现金支付（差旅备用金除外）。
2. 预付款比例原则上不超过合同金额的 30%；超过 30% 须财务总监审批，超过 50% 须总经理审批。
3. 尾款支付须取得验收报告；质保金一般预留 5%-10%，质保期满后支付。
4. 付款申请须附：合同编号、发票、验收单、付款计划节点。

## 六、发票要求

1. 增值税专用发票优先，普票须说明原因。
2. 发票内容须与合同标的一致，不得开具"办公用品"等笼统品名。
3. 发票税率与合同约定不一致的，须供应商出具说明并补足差额。

## 七、资产入账

采购的固定资产（单价 2000 元以上、使用年限超过 1 年）须在验收后 5 个工作日内到财务办理入账并粘贴资产标签。未入账的资产不得领用。
