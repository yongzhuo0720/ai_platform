# AI 平台使用规范

## 一、可用模型

平台当前接入三类模型：

1. **Dify 应用**（经 AI 网关转发）：问答聊天、知识库对话、知识库文件处理。凭据只存服务端，浏览器不持有。
2. **OpenAI 兼容直连模型**：DeepSeek-V3、Qwen-Max、GLM-4 等，按模型配置页维护。
3. **本地向量模型**：用于知识库检索的 embedding 计算，默认 text-embedding-3-small。

## 二、每日额度

| 角色 | 每日 Token 配额 |
|---|---|
| 普通员工 | 200,000 |
| 部门管理员 | 500,000 |
| 超级管理员 | 不限制 |

每分钟请求上限为 120 次。超出配额返回 429，次日 00:00 重置。配额用尽可向部门管理员申请临时提升，单次不超过 100,000。

## 三、知识库规范

1. 知识库可见性分三档：`public`（所有人可见）、`only_me`（仅所有者）、`partial_invisible`（按部门/角色黑名单排除）。
2. 上传文档单篇不超过 200,000 字符，分块上限 500 块。
3. 禁止上传含个人隐私、客户名单、未脱敏财务数据的文档。
4. L3 机密及以上数据禁止进入知识库。
5. 文档删除后分块同步删除，不可恢复。

## 四、检索行为说明

平台采用**混合检索**：向量召回 + 关键词召回，用 RRF（倒数排名融合，k=60）合并。命中片段注入对话上下文时按相关度降序排列，最多 8 个片段、6000 字符。

## 五、数据留存

1. AI 调用审计日志留存 180 天，记录模块、状态、tokens、耗时、会话 ID 与客户端 IP。
2. **不记录**用户提问与模型回答的正文，避免业务数据落进日志表。
3. 会话历史由 Dify 侧保存，平台不落库。
4. 审计日志仅超级管理员可查询，普通用户只能看自己的用量。

## 六、禁止行为

- 将平台 API Key 复制到外部系统或公开代码仓库
- 用平台处理违法违规内容
- 通过脚本高频调用绕过配额
- 将生成内容冒充人工创作对外发布
- 上传他人著作权文档用于训练或检索

## 七、故障处理

- 平台返回 503 `gateway_not_configured`：管理员未配置 Dify 地址或密钥，联系管理员。
- 返回 429 `rate_limited`：触发每分钟限流，等待一分钟重试。
- 返回 429 `quota_exceeded`：当日配额用尽，次日重置或申请提升。
- 上游超时：网关读取超时为 300 秒，长文档生成建议拆分提问。
- 所有错误响应含 `requestId`，报障时请提供该 ID 以便定位链路。
