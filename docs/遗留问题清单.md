|---|---|
| SSO 强制依赖 Redis | `SsoTokenBeanController` 现在强制注入 `StringRedisTemplate`（fail-closed）。SSO 登录态本就在 Redis，Redis 挂则用户无登录态；但若未来拆分部署需保证 Redis 可达 |
